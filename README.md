## Завдання 7. Дві третини списку

Файл: [`taskSevenTwoThirds/two_thirds.py`](taskSevenTwoThirds/two_thirds.py)

`getTwoThirdsNode(head)` повертає вузол під номером ⌊2n/3⌋ (рахуючи з одиниці), де n це довжина списку. Для списку з одного вузла або порожнього повертає `None`.

Довжину наперед не рахуємо. Список проходимо один раз, з двома вказівниками: `cur` іде до кінця, `slow` відстає. Коли `cur` проходить черговий вузол, `slow` робить крок, якщо тільки номер цього вузла не дає остачу 1 при діленні на 3. Тобто на кожні три вузли `cur` вказівник `slow` проходить два. Час O(n), додаткова пам'ять O(1).

Запуск:

```bash
python taskSevenTwoThirds/two_thirds.py
```

Скрипт будує списки `0 → 1 → … → n-1` з прикладу і друкує знайдений елемент:

```
n = 3, element = 1
n = 4, element = 1
n = 5, element = 2
n = 1, element = None
n = 0, element = None
```

## Завдання 8. Студенти і дисципліни

Файл: [`taskEightStudents/students.sql`](taskEightStudents/students.sql), діалект PostgreSQL.

Три таблиці:

- `student`: ПІБ, дата народження, email (унікальний), телефон, рік вступу (не раніше 1991).
- `discipline`: назва, опис, кредити і години (обидва більші за нуль).
- `student_discipline`: зв'язок багато-до-багатьох. Студент записаний на дисципліну в конкретну групу, тому номер групи зберігається тут, а не в `student`: на різних дисциплінах той самий студент може бути в різних групах. Первинний ключ `(student_id, discipline_id)` не дає записати студента на одну дисципліну двічі. При видаленні студента чи дисципліни записи зі зв'язкової таблиці видаляються каскадом.

Наприкінці файлу є запит: хто вчиться в 5-й групі на «Програмуванні». Під нього зроблено індекс `(discipline_id, group_number)`.

Перевірити можна на будь-якій базі PostgreSQL:

```bash
psql -d mydb -f taskEightStudents/students.sql
```

## Завдання 9. Цитати

Фронтенд застосунку, де можна переглядати, додавати, редагувати і видаляти цитати. Для наповнення взяті вислови викладачів НаУКМА.

**Стек:** Angular 21 (standalone-компоненти, signals, zoneless), TypeScript, Angular Material, RxJS. Тести на Vitest.

### Запуск

Потрібен Node.js 20.19+ або 22.12+.

```bash
cd taskNineQuotes
npm install
npm start          # http://localhost:4200
```

```bash
npm run build      # продакшн-збірка в dist/quotes-app
npm test           # unit-тести
```

### Як закриті вимоги

**1. Список цитат**

- Цитати показані картками в сітці. Кожна картка зроблена як мем-шаблон з картинок, на яких цитати й записували: зліва темна колонка з першою літерою прізвища автора, посередині синій блок з текстом, унизу блакитна смужка з підписом автора і кнопками «редагувати» та «видалити».
- Пагінація через `mat-paginator`: 5, 10 або 20 карток на сторінці, кнопки на першу та останню сторінку, підписи українською.
- Пошук за автором. Приймає будь-який текст, регістр не важливий, шукає входження підрядка («кир» знайде «Кирієнко О. В.»). Запит іде через 300 мс після того, як ви перестали друкувати. Поле очищається хрестиком. При новому пошуку список повертається на першу сторінку.

**2. Створення**

- Форма відкривається в діалозі кнопкою «Нова цитата».
- Кнопка «Створити» неактивна, доки дані невалідні. Нижче перелічено правила.
- Після збереження пошук скидається, відкривається перша сторінка, нова цитата стоїть першою і кілька секунд підсвічена рамкою.

**3. Редагування**

- Той самий діалог, заповнений поточними даними.
- «Зберегти» активна лише тоді, коли дані валідні і щось справді змінилося.
- Після збереження картка оновлюється на своєму місці. Сервер повторно не опитується, тож якщо відредагувати автора під час пошуку, цитата не зникає зі сторінки, навіть коли новий автор уже не підходить під фільтр.

**4. Видалення**

- Діалог підтвердження показує автора і початок тексту цитати.
- Після видалення список перезавантажується. Якщо на сторінці не лишилося жодної цитати, відкривається попередня.

**5. Сповіщення**

- Після створення, редагування і видалення внизу з'являється snackbar: «Цитату додано», «Зміни збережено», «Цитату видалено». Помилки показуються окремим червоним snackbar. Якщо збереження не вдалося, діалог лишається відкритим і показує текст помилки, введене не губиться.

### Валідація

Правила однакові у формі і на «сервері»:

| Поле | Правила |
| --- | --- |
| `author` | обов'язкове, не може складатися лише з пробілів, до 200 символів |
| `text` | обов'язкове, не може складатися лише з пробілів, до 1000 символів |

Під кожним полем є лічильник символів. Пробіли на початку і в кінці обрізаються перед збереженням.

### Бекенд

У завданні бекенду немає, тому `QuoteService` написаний як звичайний REST-клієнт на `HttpClient`, а відповідає йому мок у вигляді HTTP-інтерсептора ([`mock-backend.interceptor.ts`](taskNineQuotes/src/app/quotes/mock-backend.interceptor.ts)). Він додає затримку 350 мс, щоб було видно стани завантаження, і зберігає дані в `localStorage`, тому зміни переживають перезавантаження сторінки.

API, на яке розрахований фронтенд:

```
GET    /api/quotes?page=0&size=10&author=текст  -> { items, total, page, size }
POST   /api/quotes        { author, text }      -> Quote (201)
PUT    /api/quotes/:id    { author, text }      -> Quote
DELETE /api/quotes/:id                          -> 204
```

Щоб підключитися до справжнього сервера, приберіть `mockBackendInterceptor` з [`app.config.ts`](taskNineQuotes/src/app/app.config.ts). Щоб повернути демо-цитати, видаліть з `localStorage` ключ `quotes-app.mock-db.v2`.

### Оформлення

- Фон сторінки зроблений як аркуш у клітинку з червоним полем, ніби цитати записали на парі.
- Шрифти: Caveat (рукописний) для тексту цитат і підпису автора, Montserrat для всього іншого.
- Кольори взяті з мем-шаблону і логотипу НаУКМА: синій `#1F7BFF`, блакитний `#BDEBFF`, темно-синій `#062159`.
- Кути всюди прямі, у карток і кнопки «Нова цитата» жорстка тінь. Картка при наведенні трохи піднімається. Якщо в системі вимкнені анімації, картки не рухаються.
- Світла і темна тема. Перемикач у шапці, вибір запам'ятовується. Якщо ви ще нічого не вибирали, береться системна тема.
- Верстка працює і на телефоні.

### Тести

`npm test` запускає 7 тестів:

- мок-бекенд: пагінація, пошук без урахування регістру і за підрядком, нова цитата стає першою, оновлення і видалення, ліміти полів;
- форма: кнопка підтвердження неактивна для невалідних даних, а при редагуванні ще й доти, доки нічого не змінено.
